# 🚀 Social Media Marketing (SMM) Panel Landing Page

A modern, high-converting, and pixel-perfect SMM Panel Landing Page built with **Next.js**, **Tailwind CSS**, and **Framer Motion**. Designed with fully responsive components, interactive platform switching tabs, dynamic FAQ accordions, and custom SVG visual vectors.

---
🌐 **Live Demo:** [https://smm-pannel-design-client.vercel.app](https://smm-pannel-design-client.vercel.app)

## ✨ Features

- **Pixel-Perfect UI:** Built with precise orange-themed vector arcs, floating 3D overlapping graphics, and custom glassmorphism components.
- **Dynamic Platform Tabs:** Smooth service switching between Facebook, Instagram, YouTube, TikTok, and more.
- **Interactive FAQ Accordion:** Clean two-column expandable accordion with active state styling.
- **Smooth Animations:** Integrated Framer Motion transitions for hover effects, card elevation, and smooth tab rendering.
- **Fully Responsive:** Optimized for all screen sizes (Mobile, Tablet, and Desktop).
